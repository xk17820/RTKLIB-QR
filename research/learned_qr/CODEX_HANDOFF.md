# RTKLIB-QR 接手说明

已确认的用户要求：保留原有整数固定流程，只学习 Q/R，不加 bias 分支。仓库为 xk17820/RTKLIB-QR，原型在 research/learned-qr 分支的 research/learned_qr/。本次提交只导入原型，没有对上游核心文件应用补丁。

## 接手顺序

1. 核对当前分支和本 README 的状态边界，不从“存在网络文件”推断完整训练已经实现。先执行 26 项组件测试。
2. 按 README 在全新本地集成分支上应用锁定源版本的补丁。保留 main 和现有工作，不强推、不覆盖已有目录。验证 resamb_LAMBDA、manage_amb_LAMBDA、holdamb、ddcov 函数文本未变。
3. 重编译整个 RTKLIB，使用同一配置和同一观测验证 MODE=off 与原版的解算一致性；分别记录编译和回放证据。
4. 实现真实 GNSS 可微 FLOAT 训练：加载流动站/基站原始观测和星历，按当前状态重算观测/Jacobian，维护单差模糊度和周跳重置；核对 C/Python 的状态顺序、单位、时间、Q 的离散形式和双差相关项。
5. 用时刻、坐标框架和参考点一致的参考轨迹构建 ENU 位置损失；真值只用于损失/评估，不可作推理特征。增加有效参考掩码、连续序列分段和梯度检查，不能用合成示例替代真实 GNSS 适配器。
6. 按独立日期/轨迹划分训练、验证和测试。先只学 R，再交替训练 Q/R；输出模型及训练来源信息，禁止把 synthetic 标记直接改为 trained 冒充真实训练。
7. 导出 C 端模型，比较基线、Q-only、R-only、Q/R。保留 LAMBDA，报告 FLOAT/FIX 误差、尾部误差、可用率、固定率和依据参考轨迹定义的错误固定事件。无独立数据证据不得宣称提升。

## 重要代码约束

Q 目前仅缩放 ENU 加速度驱动噪声的水平和垂直项；R 是站间单差方差倍率，不是标准差倍率，也不是直接的双差对角矩阵。不要把 rtkcmn.c 内用于创新协方差的局部 Q 误当过程噪声。新增头文件安装到顶层 src 后，要与研究目录源副本同步。

与 C 端对齐的完整训练仍需实现；C 推理模块不自带 backward。完整论述见 docs/REFERENCE_LOSS.md。每次提交区分源码接通、组件测试、真实训练和独立定位验证这四种不同状态。
