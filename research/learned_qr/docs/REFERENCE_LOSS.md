> 新版SCL-RTK已增加只读原整数候选条件位置辅助项，并同时监督实际连续FLOAT/DGPS滤波状态；SINGLE单点输出不伪造梯度。详见 [SCL_RTK.md](SCL_RTK.md)。以下保留基础一阶滤波说明，不能将其解释为对整数搜索/hold的精确反传。

# 参考位置 loss 与实际梯度链

## 已实现的路径

`RINEX + broadcast nav → C rtkpos() → Q/R 推理回调 → 原生 FLOAT 状态/协方差事件 → PyTorch 递推 → ENU参考位置误差 → backward → Q/R参数更新`。

每次训练重新遍历原始观测；C 根据当前网络产生的 Q/R 和当前估计重算残差、几何、周跳处理和参考卫星选择，不将上次基线的固定残差当作本次残差。参考轨迹只用于 Python loss，不作为位置初值、观测、网络特征或 C 输入。部署无需参考轨迹。

## 精确说明：条件一阶 EKF 梯度

这不是对整个 C 程序进行精确自动微分。正向是实际原生 RTKLIB，反向对沿当前正向路径得到的连续一阶滤波方程求导：

- 递推状态、协方差、Q/R倍率、Kalman增益和Joseph更新均保留计算图。
- 活动状态、卫星选择、剔除、初始化/重置的选择固定；重置对应状态依赖被切断。
- 每历元原生局部设计矩阵 H 及局部旋转停止梯度；使用 `dv/dx=-H`。
- 因果历史特征由 C 提取并停止梯度，但输入特征数值每次正向随当前解算重新产生。
- 保留原生模糊度共模平移的状态导数，不学习其偏差值、不新增 bias head。
- 原生/PyTorch 正向数值持续检查，并用原生数值对齐；偏差超阈值直接报错。数值对齐不补造缺失的导数。

因此本实现可以用参考位置损失训练 Q/R 网络，但得到的是**条件一阶近似梯度**，不是包含 H 的二阶状态依赖、特征反馈和全部离散切换的精确导数。不能写成“完整复现了原论文全计算图”或“对 LAMBDA 反向传播”。

训练中 AR关闭；部署和回放保留原有整数流程。网络变化会间接改变固定结果，因此 FLOAT loss 更低不保证 FIX 更好。

## Q/R 参数化

10历元时序 MLP。Q输出水平、垂直2个有界正方差倍率，作用于原有加速度驱动噪声；不替换全部状态Q。R针对卫星/频点/码相分别输出单差方差倍率，双差协方差由原 `ddcov()` 构建，包括参考卫星非对角相关项。保留原生半周附加方差。

## 数值核必须计入实验设计

长采样间隔的原始观测测试暴露了旧显式求逆更新的数值病态，所以学习路径和原生桥接采用 Cholesky 解算及 Joseph 协方差更新，不加抖动或裁剪特征值。原解算器默认关闭学习时继续走旧路径。桥接 `replay --mode off` 是稳定核基线，`--mode off --legacy` 是旧核基线；学习效果应相对于稳定核基线单独报告。

## 监督与优化

位置误差 `e = C_ecef_to_enu(reference) @ (x_float[:3] - reference)`；位置主loss为分量Huber或平方误差，U可单独加权。创新高斯NLL与log倍率正则可选。按Q/R分块交替优化，采用截断时间反传；验证路线不反传。原文还学习伪距bias、采用其他结构和目标，本工程按用户要求不包含这些分支。

格式、掩码、时间对齐、命令和验证限制见 `TRAINING.md`、`VERIFICATION.md`。
